# Assets da abckx

Arquivos aqui sobrepõem os do Authelia pelo `server.asset_path` (sem mexer no core):

- `logo.png`: logo do portal de login
- `favicon.ico`: favicon
- `locales/<idioma>/portal.json`: textos do portal (ex.: `locales/pt-BR/portal.json`)

Referência: https://www.authelia.com/configuration/miscellaneous/server/#asset_path
